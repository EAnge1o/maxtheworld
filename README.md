## 🚀 旗舰项目

<div align="left">

**[mocktape](https://github.com/EAnge1o/mocktape)** — Mock API 服务器 CLI 📼
*Mock APIs from a single file. Record real ones. Replay anywhere.*

一份配置文件生成整套带状态的 CRUD 接口;把真实 API 录制成 YAML 磁带离线回放,未命中请求自动给出"最近匹配"诊断;支持故障注入与 WebSocket 实时流量面板。零框架构建于 `node:http`,82 个测试、三平台 CI、[v1.0.0 已发布](https://github.com/EAnge1o/mocktape/releases/tag/v1.0.0)。
